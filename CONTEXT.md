# Resurface Domain Glossary

## Note

A Markdown document that may be brought back into the user's attention.

## NoteId

The durable identity of a Note. A NoteId stays with the document when its
path changes. Its persistence mechanism is recorded in the identity ADR.

## Path

The Note's current location in the vault. A path is a locator, not an
identity, and may change when Obsidian or another editor moves the Note.

## Incubating

A newly captured Note waiting for its first rediscovery. It has not yet been
classified by the user.

## Rediscovery / triage

The stage where a Note is shown again so the user can decide how much future
attention it deserves. This is not a memory test.

## Learning

A Note the user has explicitly chosen to remember. Its future schedule is
managed by FSRS.

## Suspended

A terminal review choice meaning the Note should not be shown again by
Resurface.
